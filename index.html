01 · Régression logistique

Une probabilité, via une courbe en S

z = w·x + b   →   p = σ(z) = 1 / (1 + e−z)
ŷ = 1 si p > 0,5   ·   perte = −Σ [ y·log p + (1−y)·log(1−p) ]

Principe. On pondère les variables (w·x), on ajoute un biais b, puis la sigmoïde transforme ce score en probabilité entre 0 et 1.

La frontière est la droite w·x + b = 0. Elle est linéaire : deux classes qui se chevauchent ne seront jamais bien séparées.

Cas d'usage

  • Risque crédit, scoring — le régulateur exige la probabilité de défaut, pas seulement la classe.
  • Spam, diagnostic médical — décision binaire sur variables chiffrées.
  • Modèle de référence : on teste toujours le linéaire avant le complexe.

👉 Déplacez b pour centrer la frontière rouge entre les deux couleurs. 86 % est le plafond : avec une seule variable, les points −0,6 et 0,8 restent forcément mal classés.

02 · Arbre de décision

Une cascade de questions oui / non

Gini(G) = 1 − Σi pi2   ·   on retient le découpage qui maximise la baisse de Gini

Principe. À chaque nœud, on pose la question qui sépare le mieux les classes, on coupe, puis on recommence dans chaque morceau. Arrêt : plus d'ambiguïté, ou profondeur atteinte.

Les frontières sont des rectangles : l'arbre capture les interactions entre variables et se lit comme un organigramme.

Cas d'usage

  • Scoring — « si retard > 3 mois et revenu < 2000 → refus ».
  • Triage médical, maintenance — toute décision doit s'expliquer.
  • Pour extraire des règles lisibles par un métier.

03 · Random Forest


Des arbres différents qui votent




1Bagging — chaque arbre reçoit un tirage avec remise des données d'entraînement.


2Décorrélation — à chaque nœud, on n'essaie qu'une seule variable tirée au hasard.


3Agrégation — vote majoritaire sur les k arbres.


ŷ(x) = mode { yt : t = 1…k }   ·   chaque arbre est grand et non élagué


Un arbre seul colle au bruit ; en combinant k arbres indépendants, la variance s'effondre. C'est le principe du bagging.


Cas d'usage
    

  • Référence par défaut sur données tabulaires : peu de réglages, résultats solides.

04 · SVM (machine à vecteurs de support)


La frontière à marge maximale




min ½‖w‖²   s.c.  yi(w·xi + b) ≥ 1
marge = 2 / ‖w‖   ·   K(x,z) = ϕ(x)·ϕ(z)  : linéaire · polynomial · RBF


Principe. Parmi toutes les droites séparatrices, on retient celle qui maximise la marge — l'écart le plus large entre la frontière et les points les plus proches.


Vecteurs de support : seuls ces points touchent la marge et déterminent entièrement la solution. Tous les autres sont libres.


Si les classes ne se séparent pas, un noyau projette dans un espace plus grand où une droite suffit : RBF, polynomial.


Cas d'usage
    

  • Peu d'exemples, beaucoup de variables : texte, bio-informatique, génomique.
    • 

  • Frontières nettes : classification de documents, spam.
    •

06 · Conclusion


Ce qu'il faut retenir




Régression logistique
Frontière droite, probabilité calibrée, très interprétable. Le modèle de départ, et et le seul qui reste défendable quand on doit expliquer la décision.


Arbre de décision
Règles lisibles, frontières rectangulaires. Puissant mais instable : une petite variation des données change l'arbre, et il colle au bruit.


Random Forest
La forêt lisse ce que l'arbre exagère. Excellent rapport performance / effort sur données tabulaires, sans réglage.


SVM
Marge maximale, très efficace en grande dimension et sur petits jeux. boîte noire, coûteux à entraîner.




Comment choisir ?
    

  • Il faut expliquer chaque décision → régression logistique ou arbre.
    • 

  • Il faut la probabilité de l'événement → régression logistique (calibrée).
    • 

  • Données tabulaires, beaucoup d'exemples, peu de réglage → Random Forest.
    • 

  • Peu d'exemples, beaucoup de variables (texte, bio) → SVM à noyau.
